## Lỗi gặp và xử lý

- Remote bash từ chối một dòng CRLF sau khi local Git Bash chấp nhận syntax. Đã chuẩn hóa LF và yêu cầu helper kiểm tra `bash -n` trên đúng Linux target trước khi chạy.
- `scp` không giữ executable bit trên remote upload. Helper đặt mode 0700 trong unique temp directory; không thay đổi mode trên host.
- Lần signal đầu gửi trước khi child hoàn thành `exec`, và transient unit tự unload sau stop. Lab giờ chờ xác minh `/proc/<pid>/comm`; cleanup kiểm tra LoadState và lần chạy lại đã PASS.
- Phase 0 ban đầu đánh lỗi khi bridge netfilter sysctl không tồn tại. Preflight nay phân loại đúng là optional `NOT TESTED`, vẫn in diagnostic/exit status; lần rerun inventory PASS.
- Initial run `45109328188` found ShellCheck warnings `SC2097`, `SC2098` and unused firewall output variables. Renamed the NuGet path variable and discarded firewall command output after checking exit status; run `45109563671` passed.
- Host-change gate initially used `load` as an `awk -v` variable, which conflicts with gawk's builtin. Renamed it to `average`; live rerun passed with load below the CPU count. Public-exposure gate still fails independently.
- After the approved Docker transaction, both existing SSH sessions reset and a fresh TCP/22 check initially failed. The cause remains undetermined; do not infer Docker caused it. SSH later recovered without manual SSH/firewall/network changes; a fresh key-only session, host-change gate, IPv4/IPv6 route and registry egress checks passed. The emergency timer was inactive and Docker was started again for the approved smoke. The first smoke attempt exposed an `awk` built-in variable-name conflict; the next exposed Docker's empty port-binding format `{}`. Both attempts cleaned their named container, timer and newly pulled image. The corrected smoke then passed with exact cleanup.
